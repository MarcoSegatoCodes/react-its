# React ITS Lessons

This repository contains code examples and materials for the React course at ITS Alto Adriatico. Each lesson is organized into its own branch for easy navigation.

> **Tip:** Switch between branches to access the content for each lesson.

## How to Use

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. List all branches:
   ```bash
   git branch -a
   ```
3. Checkout a lesson branch:
   ```bash
   git checkout <branch-name>
   ```
